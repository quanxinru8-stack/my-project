\# STM32F405 固件工程



本仓库包含 STM32F405 项目的源代码、驱动库、工程文件以及 EIDE/VS Code 配置。



\## 目录结构



\- `HAL\_sourcecode\_diff\_car`：主要源代码、驱动库和原始工程文件。

\- `HAL\_sourcecode\_diff\_car\_eide`：EIDE、VS Code 工程配置和辅助脚本。



\## 查看源代码



主要程序代码位于：



\- `HAL\_sourcecode\_diff\_car/src`

\- `HAL\_sourcecode\_diff\_car/lib`



工程配置位于：



\- `HAL\_sourcecode\_diff\_car/project`



\## 使用 EIDE 打开



使用 EIDE 或 VS Code 打开：



`HAL\_sourcecode\_diff\_car\_eide/Firmware\_F405.code-workspace`



\## 注意事项



`.cmsis`、`.pack`、`build` 和日志文件属于本地依赖或编译输出，不上传到 GitHub。
